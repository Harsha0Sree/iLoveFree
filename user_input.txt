I’ll put the code directly in the answer, organized by file—no ZIP or downloadable folder. The implementation below covers a web app, a vanilla-JavaScript Chrome extension, a React Native Android app, Google sign-in, password sign-in, private object storage, and queued video clipping.

One important qualification: this is a **production-oriented reference implementation**, not something I can honestly label “production-tested.” I have not executed these files together, audited them, or benchmarked their memory usage.

## 1. Scope and structure

### What this implementation does

- Plays videos uploaded to your account.
- Saves clips into private S3-compatible storage.
- Lets the extension mark a range while watching YouTube.
- Lets the extension create a clip when that YouTube URL has already been associated with an imported source in your account.
- Includes an operator-run `yt-dlp` importer for videos you own or have permission to download.
- Supports Google sign-in and email/username plus password.
- Uses browser-based device pairing for Google authentication in the extension and Android app.
- Supports original-stream copying, high-quality timestamp cuts, and lossless intermediate encoding.
- Uses a minimal black background and white text.

### What is not implemented

This does not reproduce every feature of YouTube, Instagram, and X, provide their account authentication, guarantee universal ad blocking, or implement phone-number verification. It also does not promise exact frame-index selection for variable-frame-rate sources: the controls below use timestamps.

Downloading media is not inherently copyright infringement; permissions, licensing, access restrictions, and platform terms matter. The importer is intentionally a user-operated tool rather than an unrestricted public downloading endpoint.

The repository reuse is explicit: the importer uses `yt-dlp`; the extension follows `yt_clipper`’s marker-to-processing workflow. I am not claiming to have copied code from all eight repositories. `yt_clipper` documents separate browser markers and a processing script, while `yt-dlp` documents highest-available format selection and FFmpeg-based processing. [github](https://github.com/exwm/yt_clipper)

```python
def digest(value: str) -> str:
    return hashlib.sha256(value.encode()).hexdigest()


def new_session(conn, user_id) -> str:
    token = secrets.token_urlsafe(32)
    conn.execute(
        """
        INSERT INTO sessions(token_hash, user_id, expires_at)
        VALUES (%s, %s, now() + interval '7 days')
        """,
        (digest(token), user_id),
    )
    return token


def verify_password(encoded: str | None, password: str) -> bool:
    try:
        valid = passwords.verify(
            encoded or _dummy_password_hash,
            password,
        )
        return bool(encoded) and valid
    except Exception:
        return False


def signed_download(key: str, filename: str | None = None) -> str:
    params = {"Bucket": BUCKET, "Key": key}
    if filename:
        params["ResponseContentDisposition"] = (
            f'attachment; filename="{filename}"'
        )
    return public_storage.generate_presigned_url(
        "get_object",
        Params=params,
        ExpiresIn=900,
    )
```

```python
import re
from typing import Literal
from urllib.parse import parse_qs, urlparse
from uuid import UUID

from pydantic import (
    BaseModel,
    EmailStr,
    Field,
    field_validator,
    model_validator,
)


def canonical_source(value: str | None) -> str | None:
    if not value:
        return None

    parsed = urlparse(value)
    host = (parsed.hostname or "").lower()
    path = parsed.path.rstrip("/")

    if parsed.scheme != "https" or parsed.username or parsed.password:
        raise ValueError("Use an HTTPS platform URL")

    if parsed.port not in (None, 443):
        raise ValueError("Unexpected URL port")

    if host == "youtu.be":
        video_id = path.lstrip("/")
    elif host in ("youtube.com", "www.youtube.com", "m.youtube.com"):
        if path == "/watch":
            video_id = parse_qs(parsed.query).get("v", [""])[0]
        elif path.startswith("/shorts/"):
            video_id = path.split("/")[-1]
        else:
            raise ValueError("Use a YouTube watch or Shorts URL")
    else:
        video_id = None

    if video_id is not None:
        if not re.fullmatch(r"[A-Za-z0-9_-]{11}", video_id):
            raise ValueError("Invalid YouTube video ID")
        return f"https://www.youtube.com/watch?v={video_id}"

    if host in ("instagram.com", "www.instagram.com"):
        if not re.fullmatch(r"/(?:p|reel)/[A-Za-z0-9_-]+", path):
            raise ValueError("Use an Instagram post or reel URL")
        return f"https://www.instagram.com{path}/"

    if host in ("x.com", "www.x.com", "twitter.com", "www.twitter.com"):
        if not re.fullmatch(r"/[A-Za-z0-9_]+/status/[0-9]+", path):
            raise ValueError("Use an X post URL")
        return f"https://x.com{path}"

    raise ValueError("Unsupported source platform")


class RegisterInput(BaseModel):
    email: EmailStr
    username: str = Field(
        min_length=3,
        max_length=32,
        pattern=r"^[a-zA-Z0-9_]+$",
    )
    password: str = Field(min_length=12, max_length=128)


class LoginInput(BaseModel):
    identifier: str = Field(min_length=3, max_length=254)
    password: str = Field(min_length=1, max_length=128)
    bearer: bool = False


class DeviceApproval(BaseModel):
    user_code: str = Field(
        pattern=r"^[A-Z2-7]{8}$",
    )


class DevicePoll(BaseModel):
    secret: str = Field(min_length=32, max_length=128)


class UploadInput(BaseModel):
    title: str = Field(min_length=1, max_length=160)
    size_bytes: int = Field(gt=0)
    content_type: str = Field(min_length=1, max_length=100)
    source_url: str | None = None

    @field_validator("source_url")
    @classmethod
    def normalize_source(cls, value):
        return canonical_source(value)


class ClipInput(BaseModel):
    request_id: UUID
    asset_id: UUID | None = None
    source_url: str | None = None
    start_ms: int = Field(ge=0)
    end_ms: int = Field(gt=0)
    mode: Literal["copy", "exact", "lossless"] = "exact"

    @field_validator("source_url")
    @classmethod
    def normalize_source(cls, value):
        return canonical_source(value)

    @model_validator(mode="after")
    def validate_range(self):
        if self.end_ms <= self.start_ms:
            raise ValueError("End must be after start")
        if (self.asset_id is None) == (self.source_url is None):
            raise ValueError("Supply asset_id or source_url, not both")
        return self
```

```python
@app.middleware("http")
async def browser_write_protection(request: Request, call_next):
    if request.method not in ("GET", "HEAD", "OPTIONS"):
        uses_cookie = SESSION_COOKIE in request.cookies
        has_bearer = request.headers.get(
            "authorization", ""
        ).startswith("Bearer ")

        if uses_cookie and not has_bearer:
            if request.headers.get("origin") != PUBLIC_URL:
                return Response("Invalid origin", status_code=403)

        origin = request.headers.get("origin")
        if origin and origin != PUBLIC_URL:
            if not origin.startswith("chrome-extension://"):
                return Response("Invalid origin", status_code=403)

    response = await call_next(request)
    response.headers["Cache-Control"] = "no-store"
    response.headers["X-Content-Type-Options"] = "nosniff"
    return response


def rate_limit(request: Request, label: str, limit: int):
    # The API is reachable only through the gateway.
    address = request.headers.get(
        "x-real-ip",
        request.client.host if request.client else "unknown",
    )
    key = digest(f"{label}:{address}")

    with pool.connection() as conn:
        row = conn.execute(
            """
            INSERT INTO rate_limits(key, window_start, hits)
            VALUES (%s, date_trunc('minute', now()), 1)
            ON CONFLICT(key) DO UPDATE SET
                hits = CASE
                    WHEN rate_limits.window_start =
                         date_trunc('minute', now())
                    THEN rate_limits.hits + 1
                    ELSE 1
                END,
                window_start = date_trunc('minute', now())
            RETURNING hits
            """,
            (key,),
        ).fetchone()

    if row["hits"] > limit:
        raise HTTPException(429, "Too many requests")


def current_user(request: Request):
    header = request.headers.get("authorization", "")
    token = (
        header[7:]
        if header.startswith("Bearer ")
        else request.cookies.get(SESSION_COOKIE)
    )

    if not token or len(token) > 128:
        raise HTTPException(401, "Sign in required")

    with pool.connection() as conn:
        user = conn.execute(
            """
            SELECT u.id, u.email, u.username
            FROM sessions s
            JOIN users u ON u.id = s.user_id
            WHERE s.token_hash = %s AND s.expires_at > now()
            """,
            (digest(token),),
        ).fetchone()

    if not user:
        raise HTTPException(401, "Session expired")

    return user


def set_session_cookie(response: Response, token: str):
    response.set_cookie(
        SESSION_COOKIE,
        token,
        max_age=7 * 24 * 3600,
        httponly=True,
        secure=COOKIE_SECURE,
        samesite="lax",
        path="/api",
    )


@app.get("/api/health")

@app.post("/api/auth/register")
def register(
    body: RegisterInput,
    request: Request,
    response: Response,
):
    rate_limit(request, "register", 5)

    try:
        with pool.connection() as conn:
            user = conn.execute(
                """
                INSERT INTO users(email, username, password_hash)
                VALUES (%s, %s, %s)
                RETURNING id, email, username
                """,
                (
                    str(body.email).lower(),
                    body.username.lower(),
                    passwords.hash(body.password),
                ),
            ).fetchone()
            token = new_session(conn, user["id"])
    except UniqueViolation:
        raise HTTPException(409, "Account details unavailable")

    set_session_cookie(response, token)
    return user


@app.post("/api/auth/login")
def login(body: LoginInput, request: Request, response: Response):
    rate_limit(request, "login", 10)

    identifier = body.identifier.strip().lower()
    with pool.connection() as conn:
        user = conn.execute(
            """
            SELECT id, email, username, password_hash
            FROM users
            WHERE email = %s OR username = %s
            """,
            (identifier, identifier),
        ).fetchone()

        if not verify_password(
            user["password_hash"] if user else None,
            body.password,
        ):
            raise HTTPException(401, "Invalid login")

        token = new_session(conn, user["id"])

    result = {
        "id": user["id"],
        "email": user["email"],
        "username": user["username"],
    }

    if body.bearer:
        result["token"] = token
    else:
        set_session_cookie(response, token)

    return result

    user=Depends(current_user),
):
    header = request.headers.get("authorization", "")
    token = (
        header[7:]
        if header.startswith("Bearer ")
        else request.cookies.get(SESSION_COOKIE)
    )
    with pool.connection() as conn:
        conn.execute(
            "DELETE FROM sessions WHERE token_hash = %s",
            (digest(token),),
        )

    response.delete_cookie(SESSION_COOKIE, path="/api")
    return {"ok": True}

@app.get("/api/auth/google/callback")
async def google_callback(request: Request):
    try:
        token = await oauth.google.authorize_access_token(request)
        info = token["userinfo"]
        if info.get("email_verified") is not True:
            raise ValueError("Unverified email")
        subject = str(info["sub"])
        email = str(info["email"]).lower()
    except Exception:
        return RedirectResponse(
            f"{PUBLIC_URL}/?auth_error=google",
            status_code=303,
        )

    try:
        with pool.connection() as conn:
            user = conn.execute(
                "SELECT id FROM users WHERE google_sub = %s",
                (subject,),
            ).fetchone()

            if not user:
                # No implicit linking to an existing password account.
                existing = conn.execute(
                    "SELECT id FROM users WHERE email = %s",
                    (email,),
                ).fetchone()
                if existing:
                    return RedirectResponse(
                        f"{PUBLIC_URL}/?auth_error=existing_account",
                        status_code=303,
                    )

                user = conn.execute(
                    """
                    INSERT INTO users(email, username, google_sub)
                    VALUES (%s, %s, %s)
                    RETURNING id
                    """,
                    (
                        email,
                        f"google_{uuid4().hex[:16]}",
                        subject,
                    ),
                ).fetchone()

            session_token = new_session(conn, user["id"])
    except UniqueViolation:
        return RedirectResponse(
            f"{PUBLIC_URL}/?auth_error=account_conflict",
            status_code=303,
        )

    request.session.clear()
    response = RedirectResponse(PUBLIC_URL, status_code=303)
    set_session_cookie(response, session_token)
    return response

            FROM device_authorizations

            FOR UPDATE
            """,

        if not row:
            raise HTTPException(400, "Unknown device request")

            """

            FROM device_authorizations
            WHERE secret_hash = %s
            """,

        ).fetchone()["valid"]

            raise HTTPException(410, "Device request expired")

        if not row["user_id"]:
            return {"status": "pending"}

        token = new_session(conn, row["user_id"])
        conn.execute(
            """
            UPDATE device_authorizations
            SET consumed = true
            WHERE secret_hash = %s
            """,
            (digest(body.secret),),
        )

    return {"status": "approved", "token": token}


@app.post("/api/assets/upload")
def prepare_upload(
    body: UploadInput,
    request: Request,
    user=Depends(current_user),
):
    rate_limit(request, "upload", 20)

    if body.size_bytes > MAX_UPLOAD:
        raise HTTPException(413, "Source exceeds upload limit")
    if not body.content_type.startswith("video/"):
        raise HTTPException(400, "A video content type is required")

    asset_id = uuid4()
    staging_key = f"staging/{user['id']}/{asset_id}"
    object_key = f"sources/{user['id']}/{asset_id}"

    with pool.connection() as conn:
        conn.execute(
            "SELECT id FROM users WHERE id = %s FOR UPDATE",
            (user["id"],),
        )
        used = conn.execute(
            """
            SELECT COALESCE(sum(size_bytes), 0) AS bytes
            FROM assets WHERE user_id = %s
            """,
            (user["id"],),
        ).fetchone()["bytes"]

        if used + body.size_bytes > MAX_USER_SOURCE_BYTES:
            raise HTTPException(409, "Source storage quota exceeded")

        conn.execute(
            """
            INSERT INTO assets(
                id, user_id, title, source_url, object_key,
                staging_key, size_bytes, content_type, status
            )
            VALUES (%s, %s, %s, %s, %s, %s, %s, %s, 'uploading')
            """,
            (
                asset_id,
                user["id"],
                body.title,
                body.source_url,
                object_key,
                staging_key,
                body.size_bytes,
                body.content_type,
            ),
        )

    upload = public_storage.generate_presigned_post(
        Bucket=BUCKET,
        Key=staging_key,
        Fields={"Content-Type": body.content_type},
        Conditions=[
            {"Content-Type": body.content_type},
            ["content-length-range", body.size_bytes, body.size_bytes],
        ],
        ExpiresIn=300,
    )

    return {"asset_id": asset_id, "upload": upload}


@app.post("/api/assets/{asset_id}/complete")
def complete_upload(asset_id: UUID, user=Depends(current_user)):
    with pool.connection() as conn:
        asset = conn.execute(
            """
            SELECT * FROM assets
            WHERE id = %s AND user_id = %s
            FOR UPDATE
            """,
            (asset_id, user["id"]),
        ).fetchone()

        if not asset:
            raise HTTPException(404, "Asset not found")
        if asset["status"] == "ready":
            return {"ok": True}

        try:
            head = storage.head_object(
                Bucket=BUCKET,
                Key=asset["staging_key"],
            )
            if head["ContentLength"] != asset["size_bytes"]:
                raise HTTPException(400, "Uploaded size does not match")

            storage.copy_object(
                Bucket=BUCKET,
                Key=asset["object_key"],
                CopySource={
                    "Bucket": BUCKET,
                    "Key": asset["staging_key"],
                },
                CopySourceIfMatch=head["ETag"],
                ContentType=asset["content_type"],
                MetadataDirective="REPLACE",
            )
        except HTTPException:
            raise
        except Exception:
            raise HTTPException(400, "Upload is missing or invalid")

        conn.execute(
            """
            UPDATE assets
            SET status = 'ready'
            WHERE id = %s
            """,
            (asset_id,),
        )

    # The immutable source no longer depends on the upload URL.
    try:
        storage.delete_object(
            Bucket=BUCKET,
            Key=asset["staging_key"],
        )
    except Exception:
        pass

    return {"ok": True}
```

### Clipping worker

The output modes intentionally distinguish different goals:

| Mode | Output | Trade-off |
|---|---|---|
| `copy` | MKV, original video/audio streams | No re-encoding; boundaries can be approximate |
| `exact` | MP4, H.264 + AAC | Timestamp-oriented cuts; lossy, high-quality encode |
| `lossless` | MKV, FFV1 + PCM | Lossless intermediate for supported decoded formats; potentially very large |

“Lossless” here does not mean that every source’s HDR metadata, original codec packets, or container metadata survives unchanged.

#### `backend/app/worker.py`

```python
import json
import logging
import os
import signal
import subprocess
import tempfile
import time
from pathlib import Path

from boto3.s3.transfer import TransferConfig

from app.core import BUCKET, pool, storage

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s %(levelname)s %(message)s",
)

stopping = False

transfer_config = TransferConfig(
    max_concurrency=2,
    multipart_threshold=16 * 1024 * 1024,
    multipart_chunksize=16 * 1024 * 1024,
)

formats = "mov,matroska,webm,avi,mpegts,ogg"


def stop(signum, frame):
    global stopping
    stopping = True


signal.signal(signal.SIGTERM, stop)
signal.signal(signal.SIGINT, stop)


def run_checked(command, timeout):
    result = subprocess.run(
        command,
        stdin=subprocess.DEVNULL,
        stdout=subprocess.PIPE,
        stderr=subprocess.PIPE,
        timeout=timeout,
        check=False,
    )
    if result.returncode:
        raise RuntimeError("Media validation or encoding failed")
    return result.stdout


def probe(path):
    output = run_checked(
        [
            "ffprobe",
            "-v", "error",
            "-protocol_whitelist", "file,pipe",
            "-format_whitelist", formats,
            "-show_format",
            "-show_streams",
            "-of", "json",
            str(path),
        ],
        timeout=60,
    )
    return json.loads(output)


def claim_job():
    with pool.connection() as conn:
        conn.execute(
            """
            UPDATE clips
            SET status = CASE
                    WHEN attempts >= 3 THEN 'failed'
                    ELSE 'queued'
                END,
                error = CASE
                    WHEN attempts >= 3 THEN 'Worker lease expired'
                    ELSE NULL
                END,
                updated_at = now()
            WHERE status = 'running' AND lease_until < now()
            """
        )

        job = conn.execute(
            """
            SELECT *
            FROM clips
            WHERE status = 'queued'
            ORDER BY created_at
            FOR UPDATE SKIP LOCKED
            LIMIT 1
            """
        ).fetchone()

        if not job:
            return None

        conn.execute(
            """
            UPDATE clips
            SET status = 'running',
                attempts = attempts + 1,
                lease_until = now() + interval '1 hour',
                updated_at = now()
            WHERE id = %s
            """,
            (job["id"],),
        )

        asset = conn.execute(
            "SELECT * FROM assets WHERE id = %s",
            (job["asset_id"],),
        ).fetchone()

        return job, asset


def encode(job, source, output, log_path):
    start = job["start_ms"] / 1000
    duration = (job["end_ms"] - job["start_ms"]) / 1000

    common = [
        "ffmpeg",
        "-hide_banner",
        "-nostdin",
        "-loglevel", "error",
        "-y",
        "-protocol_whitelist", "file,pipe",
        "-format_whitelist", formats,
    ]

    if job["mode"] == "copy":
        command = common + [
            "-ss", f"{start:.6f}",
            "-i", str(source),
            "-t", f"{duration:.6f}",
            "-map", "0:v:0",
            "-map", "0:a:0?",
            "-c", "copy",
            "-avoid_negative_ts", "make_zero",
            str(output),
        ]
    else:
        # Output-side seeking prioritizes timestamp accuracy over speed.
        command = common + [
            "-i", str(source),
            "-ss", f"{start:.6f}",
            "-t", f"{duration:.6f}",
            "-map", "0:v:0",
            "-map", "0:a:0?",
            "-map_metadata", "-1",
            "-threads", "2",
        ]

        if job["mode"] == "lossless":
            command += [
                "-c:v", "ffv1",
                "-level", "3",
                "-c:a", "pcm_s32le",
            ]
        else:
            command += [
                "-c:v", "libx264",
                "-preset", "medium",
                "-crf", "18",
                "-pix_fmt", "yuv420p",
                "-c:a", "aac",
                "-b:a", "256k",
                "-movflags", "+faststart",
            ]

        command += [str(output)]

    with open(log_path, "wb") as log:
        result = subprocess.run(
            command,
            stdin=subprocess.DEVNULL,
            stdout=subprocess.DEVNULL,
            stderr=log,
            timeout=1800,
            check=False,
        )

    if result.returncode:
        raise RuntimeError(
            "Encoding failed; source codec or pixel format may be unsupported"
        )


def process(job, asset):
    extension = "mp4" if job["mode"] == "exact" else "mkv"

    with tempfile.TemporaryDirectory(prefix="clipvault-") as directory:
        root = Path(directory)
        source = root / "source"
        output = root / f"clip.{extension}"
        log_path = root / "ffmpeg.log"

        # Streaming transfer, not a full source blob in Python memory.
        deadline = time.monotonic() + 300
        with open(source, "wb") as destination:
            response = storage.get_object(
                Bucket=BUCKET,
                Key=asset["object_key"],
            )
            body = response["Body"]
            total = 0
            try:
                while True:
                    if time.monotonic() > deadline:
                        raise RuntimeError("Source transfer timed out")
                    chunk = body.read(1024 * 1024)
                    if not chunk:
                        break
                    total += len(chunk)
                    if total > asset["size_bytes"]:
                        raise RuntimeError("Source size mismatch")
                    destination.write(chunk)
            finally:
                body.close()

        if total != asset["size_bytes"]:
            raise RuntimeError("Incomplete source transfer")

        info = probe(source)
        video_streams = [
            stream
            for stream in info.get("streams", [])
            if stream.get("codec_type") == "video"
        ]
        if not video_streams:
            raise RuntimeError("Source contains no video stream")

        duration = float(info.get("format", {}).get("duration", 0))
        if duration <= 0:
            raise RuntimeError("Source duration is unavailable")
        if job["end_ms"] > int(duration * 1000):
            raise RuntimeError("Selected end is beyond source duration")

        encode(job, source, output, log_path)

        if not output.exists() or output.stat().st_size == 0:
            raise RuntimeError("Encoder produced an empty clip")

        output_info = probe(output)
        if not any(
            stream.get("codec_type") == "video"
            for stream in output_info.get("streams", [])
        ):
            raise RuntimeError("Output contains no video stream")

        key = f"clips/{job['user_id']}/{job['id']}.{extension}"
        storage.upload_file(
            str(output),
            BUCKET,
            key,
            ExtraArgs={
                "ContentType": (
                    "video/mp4"
                    if extension == "mp4"
                    else "video/x-matroska"
                )
            },
            Config=transfer_config,
        )

        with pool.connection() as conn:
            conn.execute(
                """
                UPDATE clips
                SET status = 'ready',
                    object_key = %s,
                    size_bytes = %s,
                    error = NULL,
                    lease_until = NULL,
                    updated_at = now()
                WHERE id = %s AND status = 'running'
                """,
                (key, output.stat().st_size, job["id"]),
            )


def main():
    pool.wait(timeout=30)

    while not stopping:
        claimed = claim_job()

        if not claimed:
            time.sleep(2)
            continue

        job, asset = claimed
        logging.info("Processing clip %s", job["id"])

        try:
            process(job, asset)
        except Exception as exc:
            logging.exception("Clip %s failed", job["id"])
            message = (
                str(exc)
                if isinstance(exc, RuntimeError)
                else "Processing failed"
            )
            with pool.connection() as conn:
                conn.execute(
                    """
                    UPDATE clips
                    SET status = 'failed',
                        error = %s,
                        lease_until = NULL,
                        updated_at = now()
                    WHERE id = %s
                    """,
                    (message[:300], job["id"]),
                )

    pool.close()


if __name__ == "__main__":
    main()
```

### Authorized-source importer

This is where `yt-dlp` is actually reused. It downloads the best available video plus audio without deliberately limiting resolution, then uploads the result to the account.

YouTube extraction may additionally require a supported JavaScript runtime and `yt-dlp-ejs`; the upstream repository explicitly identifies those requirements. A successful install is not a guarantee that every platform URL remains downloadable. [github](https://github.com/yt-dlp/yt-dlp)

#### `backend/app/import_media.py`

```python
import argparse
import getpass
import mimetypes
import subprocess
import tempfile
from pathlib import Path

import httpx

from app.models import canonical_source


def checked(response):
    response.raise_for_status()
    return response.json()


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--api", required=True)
    parser.add_argument("--url", required=True)
    parser.add_argument("--title", default="Imported source")
    args = parser.parse_args()

    source_url = canonical_source(args.url)

    confirmation = input(
        "Type YES if you own this media or have permission to download it: "
    )
    if confirmation != "YES":
        raise SystemExit("Import cancelled")

    identifier = input("ClipVault email or username: ")
    password = getpass.getpass("ClipVault password: ")

    api = args.api.rstrip("/")

    with httpx.Client(timeout=60) as client:
        login = checked(
            client.post(
                f"{api}/auth/login",
                json={
                    "identifier": identifier,
                    "password": password,
                    "bearer": True,
                },
            )
        )
        headers = {"Authorization": f"Bearer {login['token']}"}

        try:
            with tempfile.TemporaryDirectory() as directory:
                template = str(Path(directory) / "source.%(ext)s")

                subprocess.run(
                    [
                        "yt-dlp",
                        "--ignore-config",
                        "--no-playlist",
                        "--js-runtimes", "node",
                        "--max-filesize", "1G",
                        "-f", "bv*+ba/b",
                        "--merge-output-format", "mkv",
                        "-o", template,
                        source_url,
                    ],
                    check=True,
                    timeout=1800,
                )

                files = [
                    path
                    for path in Path(directory).glob("source.*")
                    if path.suffix not in (".part", ".ytdl", ".json")
                ]
                if len(files) != 1:
                    raise RuntimeError("Expected one downloaded media file")

                path = files[0]
                content_type = (
                    mimetypes.guess_type(path.name)[0]
                    or "video/x-matroska"
                )

                prepared = checked(
                    client.post(
                        f"{api}/assets/upload",
                        headers=headers,
                        json={
                            "title": args.title,
                            "source_url": source_url,
                            "size_bytes": path.stat().st_size,
                            "content_type": content_type,
                        },
                    )
                )

                upload = prepared["upload"]
                with path.open("rb") as source:
                    response = client.post(
                        upload["url"],
                        data=upload["fields"],
                        files={
                            "file": (
                                path.name,
                                source,
                                content_type,
                            )
                        },
                        timeout=600,
                    )
                    response.raise_for_status()

                checked(
                    client.post(
                        f"{api}/assets/{prepared['asset_id']}/complete",
                        headers=headers,
                    )
                )
                print(f"Imported asset: {prepared['asset_id']}")

        finally:
            client.post(
                f"{api}/auth/logout",
                headers=headers,
            )


if __name__ == "__main__":
    main()
```

```jsx
import React, { useEffect, useRef, useState } from "react";
import { createRoot } from "react-dom/client";
import "./style.css";

async function api(path, options = {}) {
  const { body, ...rest } = options;
  const response = await fetch(`/api${path}`, {
    credentials: "same-origin",
    ...rest,
    headers: {
      ...(body ? { "Content-Type": "application/json" } : {}),
      ...rest.headers
    },
    body: body ? JSON.stringify(body) : undefined
  });

  const data = await response.json().catch(() => ({}));

  if (!response.ok) {
    const detail = data.detail;
    throw new Error(
      typeof detail === "string"
        ? detail
        : JSON.stringify(detail || `HTTP ${response.status}`)
    );
  }

  return data;
}

function App() {
  const [user, setUser] = useState(null);
  const [checking, setChecking] = useState(true);
  const [registering, setRegistering] = useState(false);
  const [message, setMessage] = useState("");
  const [busy, setBusy] = useState(false);
  const [assets, setAssets] = useState([]);
  const [clips, setClips] = useState([]);
  const [selected, setSelected] = useState(null);
  const [playUrl, setPlayUrl] = useState("");
  const [start, setStart] = useState("0");
  const [end, setEnd] = useState("10");
  const [mode, setMode] = useState("exact");
  const video = useRef(null);
  const fileInput = useRef(null);

  const [pairCode, setPairCode] = useState(() => {
    const params = new URLSearchParams(location.search);
    const incoming = params.get("pair");

    if (incoming && /^[A-Z2-7]{8}$/.test(incoming)) {
      sessionStorage.setItem("pair-code", incoming);
    }

    return sessionStorage.getItem("pair-code") || "";
  });

  async function refresh() {
    const [newAssets, newClips] = await Promise.all([
      api("/assets"),
      api("/clips")
    ]);
    setAssets(newAssets);
    setClips(newClips);
  }

  async function perform(task) {
    setBusy(true);
    setMessage("");
    try {
      await task();
    } catch (error) {
      setMessage(error.message);
    } finally {
      setBusy(false);
    }
  }

  useEffect(() => {
    let alive = true;

    api("/auth/me")
      .then((value) => {
        if (alive) setUser(value);
      })
      .catch(() => {})
      .finally(() => {
        if (alive) setChecking(false);
      });

    const error = new URLSearchParams(location.search).get("auth_error");
    if (error) setMessage(`Google sign-in failed: ${error}`);

    return () => {
      alive = false;
    };
  }, []);

  useEffect(() => {
    if (!user) return;

    let disposed = false;
    let timer;
    const controller = new AbortController();

    async function poll() {
      try {
        const [newAssets, newClips] = await Promise.all([
          api("/assets", { signal: controller.signal }),
          api("/clips", { signal: controller.signal })
        ]);

        if (!disposed) {
          setAssets(newAssets);
          setClips(newClips);
        }
      } catch (error) {
        if (!disposed && error.name !== "AbortError") {
          setMessage(error.message);
        }
      } finally {
        if (!disposed) timer = setTimeout(poll, 5000);
      }
    }

    poll();

    return () => {
      disposed = true;
      clearTimeout(timer);
      controller.abort();
    };
  }, [user]);

  async function authenticate(event) {
    event.preventDefault();
    const values = Object.fromEntries(new FormData(event.currentTarget));

    await perform(async () => {
      const account = await api(
        registering ? "/auth/register" : "/auth/login",
        {
          method: "POST",
          body: registering
            ? {
                email: values.email,
                username: values.username,
                password: values.password
              }
            : {
                identifier: values.identifier,
                password: values.password
              }
        }
      );
      setUser(account);
    });
  }

  async function upload(event) {
    event.preventDefault();

    const form = event.currentTarget;
    const file = fileInput.current.files[0];

    if (!file) {
      setMessage("Choose a video first");
      return;
    }

    const values = Object.fromEntries(new FormData(form));

    await perform(async () => {
      const prepared = await api("/assets/upload", {
        method: "POST",
        body: {
          title: values.title || file.name,
          source_url: values.source_url || null,
          size_bytes: file.size,
          content_type: file.type || "video/mp4"
        }
      });

      const data = new FormData();
      for (const [key, value] of Object.entries(prepared.upload.fields)) {
        data.append(key, value);
      }
      data.append("file", file);

      const response = await fetch(prepared.upload.url, {
        method: "POST",
        body: data
      });
      if (!response.ok) throw new Error("Object-storage upload failed");

      await api(`/assets/${prepared.asset_id}/complete`, {
        method: "POST"
      });

      form.reset();
      await refresh();
      setMessage("Source uploaded");
    });
  }

  async function selectAsset(asset) {
    await perform(async () => {
      const playback = await api(`/assets/${asset.id}/play`);
      setSelected(asset);
      setPlayUrl(playback.url);
      setStart("0");
      setEnd("10");
    });
  }

  async function createClip() {
    await perform(async () => {
      if (!selected) throw new Error("Select a source");
      const startMs = Math.round(Number(start) * 1000);
      const endMs = Math.round(Number(end) * 1000);

      if (!Number.isFinite(startMs) || !Number.isFinite(endMs)) {
        throw new Error("Enter valid times");
      }

      await api("/clips", {
        method: "POST",
        body: {
          request_id: crypto.randomUUID(),
          asset_id: selected.id,
          start_ms: startMs,
          end_ms: endMs,
          mode
        }
      });

      await refresh();
      setMessage("Clip queued");
    });
  }

  async function download(clip) {
    await perform(async () => {
      const result = await api(`/clips/${clip.id}/download`);
      const anchor = document.createElement("a");
      anchor.href = result.url;
      anchor.rel = "noreferrer";
      anchor.click();
    });
  }

  async function approvePairing() {
    if (!window.confirm(
      `Authorize the device showing code ${pairCode}? Only approve a request you started.`
    )) return;

    await perform(async () => {
      await api("/auth/device/approve", {
        method: "POST",
        body: { user_code: pairCode }
      });
      sessionStorage.removeItem("pair-code");
      setPairCode("");
      setMessage("Device authorized");
    });
  }

  if (checking) {
    return <main>Checking session…</main>;
  }

  return (
    <main>
      <header>
        <h1>ClipVault</h1>
        {user && (
          <div className="row">
            <span>{user.username}</span>
            <button
              disabled={busy}
              onClick={() => perform(async () => {
                await api("/auth/logout", { method: "POST" });
                setUser(null);
                setSelected(null);
                setPlayUrl("");
                setAssets([]);
                setClips([]);
              })}
            >
              Sign out
            </button>
          </div>
        )}
      </header>

      {message && <p className="notice" role="status">{message}</p>}

      {!user ? (
        <section>
          <h2>{registering ? "Create account" : "Sign in"}</h2>

          <form onSubmit={authenticate}>
            {registering ? (
              <>
                <input
                  name="email"
                  type="email"
                  placeholder="Email"
                  required
                  autoComplete="email"
                />
                <input
                  name="username"
                  placeholder="Username"
                  pattern="[A-Za-z0-9_]{3,32}"
                  required
                  autoComplete="username"
                />
              </>
            ) : (
              <input
                name="identifier"
                placeholder="Email or username"
                required
                autoComplete="username"
              />
            )}

            <input
              name="password"
              type="password"
              placeholder="Password"
              minLength={registering ? 12 : 1}
              maxLength={128}
              autoComplete={
                registering ? "new-password" : "current-password"
              }
              required
            />

            <button disabled={busy}>
              {registering ? "Register" : "Sign in"}
            </button>
          </form>

          <p>
            <a href="/api/auth/google">Continue with Google</a>
          </p>

          <button
            onClick={() => setRegistering(!registering)}
            disabled={busy}
          >
            {registering ? "Use existing account" : "Create an account"}
          </button>
        </section>
      ) : (
        <>
          {pairCode && (
            <section>
              <h2>Authorize device</h2>
              <p>Code: {pairCode}</p>
              <p className="muted">
                Approve only if this matches a request you just started.
              </p>
              <button disabled={busy} onClick={approvePairing}>
                Approve this device
              </button>
            </section>
          )}

          <section>
            <h2>Upload source</h2>

            <form onSubmit={upload}>
              <input
                name="title"
                placeholder="Title"
                maxLength={160}
              />
              <input
                name="source_url"
                placeholder="Optional YouTube / Instagram / X source URL"
                type="url"
              />
              <input
                ref={fileInput}
                type="file"
                accept="video/*"
                required
              />

              <p className="muted">

          <section>
```

That is a low-overhead design—not a measured RAM guarantee or proof that leaks are impossible.

#### `extension/background.js`

```javascript
const API = "http://localhost:8080/api";

async function request(path, body, authenticated = true) {
  const stored = await chrome.storage.session.get("token");

  if (authenticated && !stored.token) {
    throw new Error("Open ClipVault extension and sign in first");
  }

  const response = await fetch(`${API}${path}`, {
    method: body ? "POST" : "GET",
    credentials: "omit",
    headers: {
      ...(body ? { "Content-Type": "application/json" } : {}),
      ...(authenticated
        ? { Authorization: `Bearer ${stored.token}` }
        : {})
    },
    body: body ? JSON.stringify(body) : undefined,
    signal: AbortSignal.timeout(15000)
  });

  const data = await response.json().catch(() => ({}));

  if (!response.ok) {
    throw new Error(
      typeof data.detail === "string"
        ? data.detail
        : `Request failed: ${response.status}`
    );
  }

  return data;
}

function watchUrl(raw) {
  const url = new URL(raw);

  if (
    url.origin !== "https://www.youtube.com" ||
    url.pathname !== "/watch"
  ) {
    throw new Error("Only YouTube watch pages are supported");
  }

  const id = url.searchParams.get("v");
  if (!/^[A-Za-z0-9_-]{11}$/.test(id || "")) {
    throw new Error("Invalid video ID");
  }

  return `https://www.youtube.com/watch?v=${id}`;
}

async function handle(message, sender) {
  if (message.type === "CLIP") {
    const actualUrl = sender.url || sender.tab?.url;
    const sourceUrl = watchUrl(actualUrl);

    if (
      !Number.isSafeInteger(message.start_ms) ||
      !Number.isSafeInteger(message.end_ms) ||
      message.start_ms < 0 ||
      message.end_ms <= message.start_ms
    ) {
      throw new Error("Invalid clip range");
    }

    if (!["copy", "exact", "lossless"].includes(message.mode)) {
      throw new Error("Invalid output mode");
    }

    return request("/clips", {
      request_id: crypto.randomUUID(),
      source_url: sourceUrl,
      start_ms: message.start_ms,
      end_ms: message.end_ms,
      mode: message.mode
    });
  }

  // Authentication actions are permitted only from extension pages.
  if (!sender.url?.startsWith(chrome.runtime.getURL(""))) {
    throw new Error("Invalid sender");
  }

  if (message.type === "AUTH_START") {
    const pending = await request("/auth/device", {}, false);
    await chrome.storage.session.set({ pending });
    return pending;
  }

  if (message.type === "AUTH_POLL") {
    const { pending } = await chrome.storage.session.get("pending");
    if (!pending) throw new Error("Start sign-in first");

    const result = await request(
      "/auth/device/poll",
      { secret: pending.secret },
      false
    );

    if (result.status === "approved") {
      await chrome.storage.session.set({ token: result.token });
      await chrome.storage.session.remove("pending");
    }

    return { status: result.status };
  }

  if (message.type === "AUTH_STATUS") {
    const data = await chrome.storage.session.get(["token", "pending"]);
    return {
      signedIn: Boolean(data.token),
      pendingCode: data.pending?.user_code || null
    };
  }

  if (message.type === "LOGOUT") {
    try {
      await request("/auth/logout", {});
    } finally {
      await chrome.storage.session.clear();
    }
    return { ok: true };
  }

  throw new Error("Unknown action");
}

chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  handle(message, sender)
    .then((data) => sendResponse({ ok: true, data }))
    .catch((error) => sendResponse({
      ok: false,
      error: error.message
    }));

  return true;
});
```

```javascript
      ? "Signed in"
      : result.pendingCode
        ? `Approve code ${result.pendingCode} in your browser, then reopen this popup and finish sign-in.`
```

#### `mobile/App.js`

```jsx
import React, { useEffect, useRef, useState } from "react";
import {
  Alert,
  AppState,
  Button,
  SafeAreaView,
  ScrollView,
  StyleSheet,
  Text,
  TextInput,
  View
} from "react-native";

import * as Crypto from "expo-crypto";
import * as DocumentPicker from "expo-document-picker";
import * as FileSystem from "expo-file-system/legacy";
import * as SecureStore from "expo-secure-store";
import * as Sharing from "expo-sharing";
import * as WebBrowser from "expo-web-browser";
import { VideoView, useVideoPlayer } from "expo-video";

const API = process.env.EXPO_PUBLIC_API_URL?.replace(/\/$/, "");
const TOKEN_KEY = "clipvault-token";

async function request(path, token, body, signal) {
  if (!API) throw new Error("EXPO_PUBLIC_API_URL is not configured");

  const response = await fetch(`${API}${path}`, {
    method: body ? "POST" : "GET",
    headers: {
      ...(body ? { "Content-Type": "application/json" } : {}),
      ...(token ? { Authorization: `Bearer ${token}` } : {})
    },
    body: body ? JSON.stringify(body) : undefined,
    signal
  });

  const data = await response.json().catch(() => ({}));

  if (!response.ok) {
    throw new Error(
      typeof data.detail === "string"
        ? data.detail
        : `Request failed: ${response.status}`
    );
  }

  return data;
}

function SourcePlayer({ url, onMarkStart, onMarkEnd }) {
  const player = useVideoPlayer(url, (instance) => {
    instance.loop = false;
  });

  return (
    <View>
      <VideoView
        style={styles.video}
        player={player}
        nativeControls
        allowsFullscreen
      />

      <View style={styles.row}>
        <Button
          title="Mark start"
          color="#777"
          onPress={() => onMarkStart(player.currentTime.toFixed(3))}
        />
        <Button
          title="Mark end"
          color="#777"
          onPress={() => onMarkEnd(player.currentTime.toFixed(3))}
        />
      </View>
    </View>
  );
}

export default function App() {
  const [token, setToken] = useState(null);
  const [loaded, setLoaded] = useState(false);
  const [identifier, setIdentifier] = useState("");
  const [password, setPassword] = useState("");
  const [message, setMessage] = useState("");
  const [busy, setBusy] = useState(false);
  const [assets, setAssets] = useState([]);
  const [clips, setClips] = useState([]);
  const [selected, setSelected] = useState(null);
  const [playUrl, setPlayUrl] = useState("");
  const [sourceUrl, setSourceUrl] = useState("");
  const [start, setStart] = useState("0");
  const [end, setEnd] = useState("10");
  const [mode, setMode] = useState("exact");
  const [pending, setPending] = useState(null);

  const mounted = useRef(true);
  const authController = useRef(null);

  useEffect(() => {
    mounted.current = true;

    SecureStore.getItemAsync(TOKEN_KEY)
      .then((value) => {
        if (mounted.current) setToken(value);
      })
      .finally(() => {
        if (mounted.current) setLoaded(true);
      });

    return () => {
      mounted.current = false;
      authController.current?.abort();
    };
  }, []);

  async function saveToken(value) {
    await SecureStore.setItemAsync(TOKEN_KEY, value);
    if (mounted.current) {
      setToken(value);
      setPassword("");
      setPending(null);
    }
  }

  async function perform(task) {
    setBusy(true);
    setMessage("");

    try {
      await task();
    } catch (error) {
      if (mounted.current && error.name !== "AbortError") {
        setMessage(error.message);
      }
    } finally {
      if (mounted.current) setBusy(false);
    }
  }

  async function refresh() {
    const [nextAssets, nextClips] = await Promise.all([
      request("/assets", token),
      request("/clips", token)
    ]);
    if (mounted.current) {
      setAssets(nextAssets);
      setClips(nextClips);
    }
  }

  useEffect(() => {
    if (!token) return;

    let disposed = false;
    let timer;
    let controller = new AbortController();

    async function poll() {
      if (disposed) return;

      if (AppState.currentState !== "active") {
        timer = setTimeout(poll, 5000);
        return;
      }

      try {
        const [nextAssets, nextClips] = await Promise.all([
          request("/assets", token, undefined, controller.signal),
          request("/clips", token, undefined, controller.signal)
        ]);

        if (!disposed) {
          setAssets(nextAssets);
          setClips(nextClips);
        }
      } catch (error) {
        if (!disposed && error.name !== "AbortError") {
          setMessage(error.message);
        }
      } finally {
        if (!disposed) timer = setTimeout(poll, 5000);
      }
    }

    const subscription = AppState.addEventListener("change", (state) => {
      if (state !== "active") {
        controller.abort();
      } else {
        controller = new AbortController();
      }
    });

    poll();

    return () => {
      disposed = true;
      clearTimeout(timer);
      controller.abort();
      subscription.remove();
    };
  }, [token]);

  async function passwordLogin() {
    await perform(async () => {
      const result = await request("/auth/login", null, {
        identifier,
        password,
        bearer: true
      });
      await saveToken(result.token);
    });
  }

  async function startBrowserLogin() {
    await perform(async () => {
      const result = await request("/auth/device", null, {});
      setPending(result);
      await WebBrowser.openBrowserAsync(result.verification_url);
      setMessage("Return here after approving, then tap Finish sign-in.");
    });
  }

  async function finishBrowserLogin() {
    if (!pending) return;

    await perform(async () => {
      authController.current?.abort();
      const controller = new AbortController();
      authController.current = controller;

      const result = await request(
        "/auth/device/poll",
        null,
        { secret: pending.secret },
        controller.signal
      );

      if (result.status === "approved") {
        await saveToken(result.token);
      } else {
        setMessage("Waiting for approval in the browser.");
      }
    });
  }

  async function uploadSource() {
    await perform(async () => {
      const result = await DocumentPicker.getDocumentAsync({
        type: "video/*",
        copyToCacheDirectory: true,
        multiple: false
      });

      if (result.canceled) return;

      const file = result.assets[0];

      try {
        const info = await FileSystem.getInfoAsync(file.uri);
        if (!info.exists || !info.size) {
          throw new Error("Unable to read selected file");
        }

        const prepared = await request("/assets/upload", token, {
          title: file.name,
          source_url: sourceUrl || null,
          size_bytes: info.size,
          content_type: file.mimeType || "video/mp4"
        });

        const upload = await FileSystem.uploadAsync(
          prepared.upload.url,
          file.uri,
          {
            httpMethod: "POST",
            uploadType: FileSystem.FileSystemUploadType.MULTIPART,
            fieldName: "file",
            mimeType: file.mimeType || "video/mp4",
            parameters: prepared.upload.fields
          }
        );

        if (upload.status < 200 || upload.status >= 300) {
          throw new Error("Object-storage upload failed");
        }

        await request(
          `/assets/${prepared.asset_id}/complete`,
          token,
          {}
        );

        setSourceUrl("");
        await refresh();
        setMessage("Source uploaded");
      } finally {
        if (file.uri.startsWith(FileSystem.cacheDirectory)) {
          await FileSystem.deleteAsync(file.uri, {
            idempotent: true
          }).catch(() => {});
        }
      }
    });
  }

  async function openAsset(asset) {
    await perform(async () => {
      const result = await request(`/assets/${asset.id}/play`, token);
      setSelected(asset);
      setPlayUrl(result.url);
      setStart("0");
      setEnd("10");
    });
  }

  async function createClip() {
    await perform(async () => {
      if (!selected) throw new Error("Select a source first");

      const startMs = Math.round(Number(start) * 1000);
      const endMs = Math.round(Number(end) * 1000);

      if (!Number.isFinite(startMs) || !Number.isFinite(endMs)) {
        throw new Error("Enter valid times");
      }

      await request("/clips", token, {
        request_id: Crypto.randomUUID(),
        asset_id: selected.id,
        start_ms: startMs,
        end_ms: endMs,
        mode
      });

      await refresh();
      setMessage("Clip queued");
    });
  }

  async function exportClip(clip) {
    await perform(async () => {
      const result = await request(
        `/clips/${clip.id}/download`,
        token
      );
      const path = `${FileSystem.cacheDirectory}${result.filename}`;

      try {
        await FileSystem.downloadAsync(result.url, path);

        if (!(await Sharing.isAvailableAsync())) {
          throw new Error("Sharing is unavailable on this device");
        }

        await Sharing.shareAsync(path);
      } finally {
        await FileSystem.deleteAsync(path, {
          idempotent: true
        }).catch(() => {});
      }
    });
  }

  async function logout() {
    await perform(async () => {
      try {
        await request("/auth/logout", token, {});
      } finally {
        await SecureStore.deleteItemAsync(TOKEN_KEY);
        setToken(null);
        setSelected(null);
        setPlayUrl("");
        setAssets([]);
        setClips([]);
      }
    });
  }

  if (!loaded) {
    return (
      <SafeAreaView style={styles.root}>
        <Text style={styles.text}>Loading…</Text>
      </SafeAreaView>
    );
  }

  return (
    <SafeAreaView style={styles.root}>
      <ScrollView contentContainerStyle={styles.container}>
        <Text style={styles.heading}>ClipVault</Text>

        {!!message && <Text style={styles.text}>{message}</Text>}

        {!token ? (
          <View style={styles.section}>
            <TextInput
              style={styles.input}
              placeholder="Email or username"
              placeholderTextColor="#999"
              value={identifier}
              onChangeText={setIdentifier}
              autoCapitalize="none"
              autoComplete="username"
            />

            <TextInput
              style={styles.input}
              placeholder="Password"
              placeholderTextColor="#999"
              value={password}
              onChangeText={setPassword}
              secureTextEntry
              autoComplete="current-password"
            />

            <Button
              title="Sign in"
              color="#777"
              disabled={busy}
              onPress={passwordLogin}
            />

            <View style={styles.gap} />

            <Button
              title="Google / browser sign-in"
              color="#777"
              disabled={busy}
              onPress={startBrowserLogin}
            />

            {pending && (
              <>
                <Text style={styles.text}>
                  Device code: {pending.user_code}
                </Text>
                <Button
                  title="Finish sign-in"
                  color="#777"
                  disabled={busy}
                  onPress={finishBrowserLogin}
                />
              </>
            )}

            <Text style={styles.muted}>
              New accounts can be created in the browser.
            </Text>
          </View>
        ) : (
          <>
            <Button
              title="Sign out"
              color="#777"
              disabled={busy}
              onPress={logout}
            />

            <View style={styles.section}>
              <Text style={styles.subheading}>Upload source</Text>

              <TextInput
                style={styles.input}
                placeholder="Optional platform source URL"
                placeholderTextColor="#999"
                value={sourceUrl}
                onChangeText={setSourceUrl}
                autoCapitalize="none"
                keyboardType="url"
              />

              <Text style={styles.muted}>
                Upload only media you own or are authorized to use.
              </Text>

              <Button
                title="Choose and upload video"
                color="#777"
                disabled={busy}
                onPress={uploadSource}
              />
            </View>

            <View style={styles.section}>
              <Text style={styles.subheading}>Sources</Text>

              {assets.map((asset) => (
                <View key={asset.id} style={styles.item}>
                  <Text style={styles.text}>{asset.title}</Text>
```

## 5. Running and release checks

### Start the backend and web

From the project root:

```bash
cp .env.example .env
```

Generate a random OAuth-state secret:

```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

Put it in `.env`, change the database/storage passwords, and ensure `DATABASE_URL` matches the configured database password.

Then:

```bash
docker compose up --build -d
docker compose logs -f api worker
```

Open [the local web app](http://localhost:8080).

The SQL initialization runs only when PostgreSQL starts with a new data volume. Editing `schema.sql` does not migrate an existing database.

### Configure Google sign-in

Set:

```dotenv
GOOGLE_CLIENT_ID=your-client-id
GOOGLE_CLIENT_SECRET=your-client-secret
```

Register this exact development callback in your Google OAuth application:

```text
http://localhost:8080/api/auth/google/callback
```

Then restart the API:

```bash
docker compose up -d --force-recreate api
```

For production, use an HTTPS `PUBLIC_URL`, its exact HTTPS callback, and:

```dotenv
COOKIE_SECURE=true
```

### Load the Chrome extension

1. Open Chrome’s extension management page.
2. Enable developer mode.
3. Choose “Load unpacked.”
4. Select the `extension` directory.
5. Open the extension popup and start browser sign-in.
6. Approve the displayed code in the web app.
7. Reopen the popup and finish sign-in.

For a production domain, change the API origin in `background.js`, the library URL in `popup.js`, and `host_permissions` in `manifest.json`.

```bash
cd mobile
```

A phone cannot use your computer’s `localhost`. Configure a phone-reachable HTTPS origin for the API and a phone-reachable object-storage endpoint before testing uploads or playback.

### Import a platform source

Use a local Python environment with the backend dependencies, FFmpeg, and a supported JavaScript runtime installed:

```bash
cd backend

python -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt

python -m app.import_media \
  --api http://localhost:8080/api \
  --url "https://www.youtube.com/watch?v=YOUR_VIDEO_ID" \
  --title "My authorized source"
```

After importing that source, the extension can create cloud clips while you watch the matching YouTube video.

Highest-available downloads may use containers or codecs that the web player cannot play directly. This implementation preserves those source files for clipping; it does not include a separate browser-compatible preview-transcoding pipeline.

### Before public deployment

The files above include account ownership checks, opaque revocable sessions, private storage, bounded upload requests, idempotent job creation, worker leases, parameterized SQL, and subprocess argument arrays. However, the following remain release requirements:

- Generate and commit dependency lockfiles; pin container images to reviewed digests.
- Replace MinIO root credentials with bucket-scoped application credentials.
- Add migration tooling rather than relying on initialization SQL.
- Add email verification, password reset, and explicit authenticated Google-account linking.
- Add verified phone ownership before offering phone/password authentication.
- Add abandoned-upload cleanup, session cleanup, device-code cleanup, asset deletion, and output-storage quotas.
- Add a browser-compatible preview pipeline for unsupported source codecs.
- Add true decoded-frame indexing if exact frame-number selection is required.
- Test OAuth failures, upload interruption, duplicate submissions, job recovery, ownership isolation, and malicious media inputs.
- Load-test the API and measure extension/Android memory usage on actual devices.
- Add monitoring, backup/restore testing, storage lifecycle policies, and an abuse-reporting process.

This is the complete inline source for the scoped implementation described above—not a claim that all of your original platform-cloning, ad-blocking, authentication, and frame-selection requirements have been completed.
